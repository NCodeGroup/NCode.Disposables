This page takes you from an empty project to code that runs when a scope ends, disposes several resources in order, shares one resource and disposes asynchronously.

## Install

```sh
dotnet add package NCode.Disposables
```

The package is one assembly with no dependencies. Every type is in the namespace `NCode.Disposables`.
