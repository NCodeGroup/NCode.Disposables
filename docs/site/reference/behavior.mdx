## Reading the matrix

- *Safe to dispose twice:* a second `Dispose` does nothing. [Once, or on every call](/concepts/once-or-every-time/) explains the types that run their action again.
- *Reports `IsDisposed`:* it implements `IDisposalStatus`.
- *Allocation-free:* a struct, or one shared instance.
- *Sync and async forms:* `Disposable` and `AsyncDisposable` both create it.
- *Disposes a late resource:* a resource handed to it after disposal is disposed at once, and "Does not apply" marks a type that is handed no resource. [Disposal status and late resources](/concepts/disposal-status/) explains the rule.
