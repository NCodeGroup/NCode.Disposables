## Extension members

`DisposableExtensions`, `AsyncDisposableExtensions`, `SemaphoreSlimExtensions` and `ReaderWriterLockSlimExtensions` are C# 14 `extension` blocks compiled to ordinary static extension methods, so a project on an earlier C# version calls them the same way, or in their static form, `DisposableExtensions.DisposeAll(items)`.
