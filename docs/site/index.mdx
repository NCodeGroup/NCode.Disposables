## What it does. What it does not.

<CardGrid>
<Card title="It does">

- Run each class's cleanup once, even when several threads dispose it, unless a member named `Repeatable` asks for
  every call.
- Dispose a collection's items in reverse order, every one even when one throws.
- Dispose a resource handed to a holder that is already disposed.
  [ADR-1004](https://github.com/NCodeGroup/NCode.Disposables/blob/main/docs/decisions/1004-a-resource-handed-to-a-disposed-holder-is-disposed.md)
- Share one resource through reference-counted leases.
- Dispose a resource on its `SynchronizationContext`.
- Scope a `SemaphoreSlim` or `ReaderWriterLockSlim` lock in a struct that allocates nothing.

</Card>
<Card title="It does not">

- Make a struct safe to dispose twice. A value disposable, a lock scope or a lease runs again on every dispose.
  [Once, or on every call](/concepts/once-or-every-time/)
- Dispose an item that is only `IAsyncDisposable` from synchronous code: `DisposeAll()` throws
  `InvalidOperationException`.
- Dispose anything you never dispose. No type has a finalizer.
- Hide failures. The exceptions items throw reach you unless you choose a member named `IgnoringExceptions`.
- Dispose a resource on the calling thread when its context refuses the work.

</Card>
</CardGrid>

## In the package

- One assembly, `NCode.Disposables`, with every type in the namespace `NCode.Disposables`. It has no dependencies,
  performs no I/O, starts no threads and keeps no mutable static state.
- The target framework is the one the project file declares, which the badge shows and
  [nuget.org](https://www.nuget.org/packages/NCode.Disposables#supportedframeworks-body-tab) lists.
- Every C# sample on this site is a test the pull request build compiles and runs.
- The reasons behind the design are on record in
  [docs/decisions](https://github.com/NCodeGroup/NCode.Disposables/tree/main/docs/decisions).
- Apache License 2.0, copyright NCode Group. A vulnerability is reported privately, as the
  [security policy](https://github.com/NCodeGroup/NCode.Disposables/blob/main/SECURITY.md) says.
